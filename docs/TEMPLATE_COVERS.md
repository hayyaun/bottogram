# Template cover artwork

Seven project-local cover images created with the built-in image_gen tool.
No remote image service is used by the application.

## Prompt set

### quiz

Use case: stylized-concept. Asset type: a landscape cover image for one Bottogram bot template card. Create a polished editorial 3D paper-and-ceramic still life, tactile matte surfaces, precise playful geometry, soft directional studio lighting and contact shadows. Wide 16:9 composition, full-bleed solid colored backdrop, subject centered with comfortable margins, large recognizable objects occupying most of the frame. Cohesive modern software-store art direction, sophisticated rather than childish. No text, letters, digits, logos, watermark, robot mascots, UI screenshot, border or card frame. Subject: Warm butter-yellow backdrop, deep teal and apricot objects. A small sculptural quiz trophy beside three overlapping thick question-and-answer paper cards, with simple circular answer markers and one oversized teal check mark. A small star-shaped accent. Convey learning and personal scores.
